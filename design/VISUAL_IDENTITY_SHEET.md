# Visual Identity Sheet

## Mark

Use the wordmark `WITHIN REACH` with the city as a configuration label: `— Leeds`. The companion symbol is two asymmetric nested contour lines with a small origin dot. It sits naturally in the dark navigation rail and uses signal yellow for the comfortable field. It must never resemble a medical badge or location-pin cliché.

Minimum digital wordmark width: 152 px. Clear space: the cap height of `W`. Use white/signal yellow on Ink, or Ink on white. Do not stretch, outline, shadow, gradient-fill or combine with council logos without written permission.

## Signature element

The personalised **Reach Field** is the brand’s memorable element and a functional data layer. Standard reach: 2 px Ink at 45% opacity, 6/5 dash. Comfortable reach: 3 px dark-gold outline, Signal pale fill at 52%. When contours overlap, comfortable reach sits above standard reach. A hatched pattern identifies unknown network coverage.

## Icon system

Use Lucide-compatible 24 px stroke icons initially, but lock a consistent 1.75 px stroke, square line caps only where the object requires it, and never mix filled and outline families. Every icon has a visible text label. Required V1 icons: reach/contours, route, search/need, park/tree, seat, toilet, accessible toilet, Changing Places (licensed/approved mark only), health, community, Safe Place (official mark only with permission), steps, slope, crossing, surface, information, warning, current location, list and map.

## Voice

Calm and literal. Say `We don’t know whether this path is step-free` rather than `Accessibility data unavailable`. Say `Use my location` rather than `Enable geolocation`. Do not use “normal user”, “wheelchair bound”, “suffers from”, or “the disabled”.

## Photography and illustration

V1 needs no decorative photography. Use the real map and restrained line diagrams. If later editorial imagery is added, show ordinary street-level journeys and diverse ages/mobility without staged inspiration narratives. Record consent, licence, credit and expiry.

## Data-visual rules

- Routes: Fastest = Ink 2 px dashed; Easiest = Route blue 4 px solid.
- Known barrier = red triangle plus text.
- Unknown = diagonal hatch plus question-mark marker.
- Rest place = seat icon; its verified status changes the small badge, not the icon colour alone.
- Reach comparison always lists area/service counts in text below the map.

## Asset deliverables the worker must create

`brand/mark.svg`, `brand/wordmark.svg`, `brand/app-icon.svg`, maskable 192/512 PNGs, favicon, Open Graph card, map sprite sheet, licensed font files and `THIRD_PARTY_ASSETS.md`. SVGs must have titles/accessible names where used as content; decorative instances use `aria-hidden`.
